# fumi

A minimalist writing app that separates writing from editing. Inspired by [Enso](https://write.sonnet.io/).

## Features

- **Fading text** - Characters fade to near-invisible over 5 seconds, keeping focus on the current thought
- **Append-only** - No backspace, delete, undo, paste, or text selection
- **Auto-save** - Notes saved to localStorage automatically
- **Continue writing** - Reopen finished notes and keep adding to them
- **Themes** - Dark and light modes
- **Export** - Download any note as a .txt file
- **Offline & private** - No backend, no accounts. Everything stays in your browser

## Getting Started

```bash
npm install
npm run dev
```

## Tech

React + TypeScript + Vite + Zustand. Plain CSS.
